# gothic-caesar-cipher
A Caesar Cipher application supporting English, Russian, Persian, and Japanese Hiragana characters
Features

Encrypt and decrypt text using the Caesar Cipher.

Simple graphical user interface.

Dark gothic-inspired color palette.

Custom bat-themed application icon.

Windows executable (.exe) for easy use without installing Python.
How to Use

Download the executable from the Releases section.

Run the .exe file.

Enter your text and shift value.

Choose encryption or decryption.
